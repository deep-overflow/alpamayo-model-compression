# 1차 Taylor 중요도의 크기 캘리브레이션 진단 — rank는 병목인가 보호막인가

날짜: 2026-08-15 (KST) · 상태: 승인 대기

## 질문과 가설

프루닝 기준 `max(rank I_traj, rank X)`는 결합 직전에 rank_norm으로 크기 정보를 버린다.
이것이 정당한지는 스코어 자체의 품질에 달려 있다:

- 1차 Taylor 스코어 `|dL/dg|`는 "유닛 u를 제거하면 L이 이만큼 오른다"는 **크기 예측**이다
  (게이트 1→0, Δg=−1이므로 예측 ΔL = 스코어값 그대로, 손실 단위).
- 크기까지 실측과 맞으면 → rank는 정보를 버리는 병목이고, loss 단위 knapsack 결합
  (`alloc_lib` 방식의 프루닝판)에 여지가 있다.
- 순서만 맞고 크기는 엉망이면 → rank는 "가장 못 믿을 부분을 버리는" 분산 축소 장치로
  정당화되고, 개선 방향은 정규화가 아니라 스코어 자체(반복 재캘리브레이션)다.

간접 증거는 이미 둘 다 있다. 양자화 트랙에서 1차 방향미분이 lm_head를 오배분했고(크기
실패), 분해 실험에서 dual − traj < 0이 teacher-forcing에서도 유지됐다(동시 제거 상호작용).
이 진단은 그것을 유닛 수준에서 직접 계량한다. 양자화 Gate G0와 동형이며, 그쪽에서
"미실행인 채로 간접 반증만 남았다"고 기록한 바로 그 측정의 프루닝판이다.

## 설계

자기완결형 러너 하나가 클립 단위로 다음을 수행한다 (`run_importance.process_clip`과 동일한
전처리·시드 규칙, `sha256(f"42:{clip_id}")`):

```
클립당:
  1. 무손상 rollout → CoC 텍스트 고정 (이후 모든 측정이 이 텍스트를 TF)
  2. dual-objective backward 1회 → 이 클립의 per-unit 예측 스코어 |dL_CoC/dg|, |dL_traj/dg|
     (run_importance와 동일 경로 — importance_v2에 의존하지 않아 텍스트/카드 불일치 없음)
  3. 무손상 reference forward → L_CoC, L_traj 기준값
     (L_traj = FM MSE, 같은 시드의 노이즈 10스텝, forward-only)
  4. 표본 유닛/그룹마다: mask_lib.PruneMasks로 끄고 같은 텍스트·같은 노이즈로
     forward-only → 실측 ΔL_CoC(u), ΔL_traj(u) (페어드, 결정론이라 노이즈 0)
```

마스킹은 slim과 기능적으로 동일함이 검증돼 있고(o_proj/down_proj 입력 0/1), Q head 마스크는
KV 캐시를 건드리지 않으므로 expert 경로도 올바르게 반영된다.

### 표본

| 항목 | 값 |
|---|---|
| 레이어 | 6개, 깊이 스팬: 1, 8, 15, 22, 29, 35 |
| Q head | 레이어당 전수 32개 (192 유닛) |
| MLP 채널 | 레이어당 48개: traj 랭크 균등 24 + coc 랭크 균등 12 + 컷 라인(39.86%) ±5% 집중 12, 중복 제거 (~288 유닛) |
| 그룹 (가법성) | 레이어당: 실제 컷의 Q bottom-13 셋 × {traj, coc, dual, jtraj} 4개 (전 멤버의 단독 ΔL 보유 → 합 대비 직접 비교 가능) + 표본 MLP 48개 중 {traj-bottom-8, random-8, cut-근방-8, traj-bottom-32, random-32} 5개 |
| 실제 컷 MLP 그룹 | 레이어당 criterion별 bottom-4898 셋 4개 (합 비교는 불가, criterion 간 실측 손상 비교용) |
| 클립 | calib_100의 앞 25개 (config 순서, 결정론) |
| 카드 | Ada 2장 (`--shard`, 클립 샤딩 — 시드가 클립 유래라 샤딩 무해) |

클립당 마스크 평가 ≈ 560회 × forward ~1.5 s ≈ 14분 → 25클립 2장 샤딩 시 **~3시간**.
backward 1회가 40.5 GB를 쓰므로 `reserve_gpu(44)`.

### 예측치와 실측치의 대응

- 예측: per-clip `|dL/dg_u|` (run_importance 관례 그대로), 집계는 클립 평균.
- 실측: per-clip 부호 있는 `ΔL(u) = L_masked − L_ref`, 집계는 (a) 부호 평균, (b) 절대값 평균 둘 다.
- 스코어의 per-clip 절대값 관례가 부호 상쇄를 못 보는 것 자체가 판독 대상이다:
  클립 간 부호가 갈리는 유닛의 비율을 별도 보고한다 (제거가 도움이 되는 클립이 있는 유닛).

## 사전 등록 게이트

- **G-CAL-A (순서)**: 레이어 내 랭크로 풀링한 Spearman ρ(예측, 실측 부호 평균 ΔL),
  축(Q/MLP) × 목적(coc/traj) 4칸. **ρ ≥ 0.7이면 순서 신뢰** (양자화 G0와 같은 임계).
- **G-CAL-B (크기)**: 실측 ΔL > 0인 유닛에 한해 log(예측) vs log(실측)의 Pearson r,
  같은 4칸. **r ≥ 0.7이면 크기에 신호 있음** → loss 단위 knapsack 결합 arm을 다음
  실험으로 승격. 미달이면 rank_norm 유지가 결론이고 정규화 실험은 하지 않는다.
  ΔL ≤ 0 유닛의 비율은 별도 보고 (Taylor-abs가 원리상 못 보는 영역).
- **G-CAL-C (가법성)**: 그룹 실측 ΔL / Σ(멤버 단독 ΔL)의 비 R. Q bottom-13(실제 컷)에서
  **중앙값 |log2 R| > 1 (2배 이상 이탈)이면 1차 가법성이 실제 작동점에서 깨진 것** →
  반복 재캘리브레이션을 최우선 후속으로 확정. k=8/32 그룹으로 이탈이 크기에 따라
  어떻게 자라는지 함께 보고.
- 보조 (게이트 아님): jlens_v2의 J 스코어와 실측 ΔL_CoC의 Spearman — J는 손상 예측이
  아니므로 크기 비교는 하지 않고 순서만 참고 보고.

## 한계 (미리 적어둠)

- 단독 ΔL은 "다른 유닛이 모두 살아있는" 조건의 실측이다. G-CAL-C가 그 한계를 그룹으로
  보완하지만, 39.86% 동시 제거 조건의 완전한 실측은 아니다 (그건 slim arm 자체다).
- 레이어 6개 표본이다. 깊이별 이질성이 크면 결론이 레이어 선택에 의존할 수 있어,
  분석에서 레이어별 수치를 개별 보고한다.
- calib 25클립이다. 예측·실측 모두 같은 클립을 쓰므로 비교 자체는 페어드이고 공정하나,
  calib_100 전체 스코어와의 표본 차이는 남는다 (스코어 재현이 목적이 아니라 캘리브레이션
  측정이 목적이므로 허용).
- FM MSE는 10스텝 midpoint 고정이라 denoise 전 구간의 대표값이지 minADE가 아니다.
  이 진단은 "스코어가 자기가 예측한다고 주장하는 손실"을 재는 것이므로 이것이 맞는 대상이다.
