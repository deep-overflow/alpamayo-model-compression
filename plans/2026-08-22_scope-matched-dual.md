# scope-matched dual — 폐루프 열세의 원인이 레이어 범위인가 (2026-08-22)

## 배경

폐루프 150씬에서 우리 dual과 동료의 LLM-Pruner arm은 **종합 점수가 구분 불가**다
(dual−lp_r50 +0.018 [−0.029,+0.066] ns, dual−lp_r50_dual +0.012 ns). 그런데 세부 지표는
계통적으로 갈린다:

| | score | col@f / any | offroad | d2gt |
|---|---|---|---|---|
| baseline | 0.750 | 0.040 / 0.133 | 0.070 | 2.89 |
| dual (36층 균일, 24.0%) | 0.828 | **0.023 / 0.067** | 0.067 | **3.32** |
| lp_r50 (30층 4–34, 25.0%) | 0.810 | 0.057 / 0.160 | **0.037** | **2.88** |

즉 **우리는 충돌이 절반, LP는 경로 정밀도(d2gt)와 오프로드가 우수**하다. 두 방법은
기준·목적함수·절단 축이 사실상 같고(둘 다 dual = max(rank I_traj, rank I_CoC), k/v 동결),
가장 큰 구조적 차이는 **레이어 범위**다: LP는 업스트림 `--block_*_layer_start/end` 관례대로
layers 4–34만 자르고 앞 4층·뒤 2층을 온전히 남긴다. 우리는 36층 균일이다.

**H-S**: d2gt/offroad 열세는 기준이 아니라 **레이어 범위** 때문이다. 앞뒤 층(저수준 공간·
차선 표현)을 보존하면 d2gt가 baseline 수준(≈2.9)으로 내려가고, 대신 중간층을 더 깊게
잘라야 하므로 충돌 이점 일부를 잃는다.

## 설계 (one-factor: 범위만 변경)

`dualscope_u40` — dual_u40_v2와 **기준·calibration·축·예산이 모두 동일**하고 절단 위치만
다르다.

- 기준: `max(rank I_traj, rank I_CoC)` (importance_v2, calib_100) — dual과 동일.
- 축: VLM Q head / MLP 채널만, expert·KV 불변 — dual과 동일.
- 범위: **layers 4–34 (30층)**, 0–3·34–35는 손대지 않음 (LP 관례와 동일).
- 예산: **정확히 −2,657,452,032** (dual_u40_v2와 파라미터 단위까지 일치). 30층에 같은
  예산을 넣으려면 층당 절단이 깊어진다 — 깊이 스케일 비율 r×36/30 = 0.4783에서
  head는 반올림 15/32, MLP 채널 수는 총량이 목표에 정확히 떨어지도록 역산:

      30층 × 15 head × 1,048,576 = 471,859,200
      나머지 2,185,592,832 / 12,288 = 177,864 채널 = 24층 × 5929 + 6층 × 5928

  잔여 1채널은 scope 앞쪽 24개 층에 하나씩 분배(결정적). 총합 = 2,657,452,032 ✓
- 선택 규칙은 다른 모든 arm과 같은 `mask_lib.select_mask_ratios`(레이어 내 최저 점수 절단).

## 사전 등록 게이트

- **S0 (무결성)**: 제거 파라미터 == 2,657,452,032 정확 일치, layers 0–3·34–35의 kept-set이
  전부 온전(32 head / 12288 채널), scope 층은 17 head / 6359–6360 채널 보존.
- **S1 (개루프, test_500)**: paired ΔminADE@6 vs dual. 방향 예측 없음(양쪽 다 정보) —
  범위를 좁히면 남은 층이 더 깊게 잘리므로 개루프는 나빠질 수 있다.
- **S2 (주 판정, 폐루프 150씬)**: d2gt와 offroad가 lp_r50 수준(≈2.9 / ≈0.04)으로 내려가는가.
  - 내려가면 → H-S 확인: "앞뒤 층 보존 = 경로 정밀도" (그리고 충돌이 오르면 트레이드오프 확정).
  - 안 내려가면 → 범위 가설 기각, d2gt 차이는 기준·정책 차이에서 온다.
  - **주의**: 폐루프 종합 점수는 n=150에서 해상도 0.067이라 score로는 판정하지 않는다.
    d2gt(연속값)와 offroad는 씬-페어드로 훨씬 민감하므로 이 둘로 판정한다.
- **S3 (부기록)**: 충돌(과실/전체), 진행도, wrong_lane, CoC degen, LingoQA.
