# Tyr-the-Pruner를 공식 절차대로 다시 빌드해 A100에서 평가

날짜: 2026-10-31. 상태: **승인됨(2026-10-31): `tyr_off`만 진행. 기존 `tyr_u40_r`의 A100 측정은 이번엔 하지 않음.**

결정된 것 (2026-10-31, 사용자):
- 보정·적합도 데이터는 calib_100 주행 클립(MoOP·LLM-Pruner와 같음). 나머지는 공식 레포 절차를 따른다.
- 오차 누적은 논문 식 5(모든 수준의 (1 − Sₑ) 가중 기대값).
- supernet 4회 + 탐색 4회(coarse-to-fine). 빌드와 평가 모두 KISTI NEURON A100.

## 1. 목적
- 논문 Tyr 행(`tyr_u40_r`)은 이 레포의 간이 포트다(반복 1회, 작은 탐색, CoC 위치 KL + expert MSE 적합도, 중앙 수준 오차 누적).
  공식 절차를 따른 Tyr를 새로 빌드해(arm `tyr_off`), 같은 제거량(2,657,452,032 = MoOP)에서 A100 표(test_2000, OOD-Val262,
  LingoQA)로 dense·MoOP·MoOP l0keep과 짝지어 잰다.

## 3. 구현 (레포 `experiments/head_analysis/`의 Tyr 포트를 고친다)
- **`run_tyr_supernet.py`:**
  - 공식 수준 격자: `Δ = weights_diff / numel`, 수준 = s + l·Δ, `l ∈ [−min(int(s//Δ),4), min(int((1−s)//Δ),4)]`, [0,1]로 자름,
    유지 수 = `int(cin·(1−sp))`. 희소율 1.0이면 0 가중치, 0.0이면 dense.
  - `--iteration R`, `--prev-supernet/--prev-config`: R≥2는 층별 중심을 `(s_prev·numel + level·Δ_prev)/numel`로 재설정.
  - 오차 누적 식 5: 블록의 모든 수준 가중치를 (1 − Sₑ)/Σ(1 − Sₑ)로 평균해 모델에 쓰고 다음 블록 입력을 만든다.
- **`run_tyr_search.py`:** 적합도 `--fitness kl_text`(top-8,192, 텍스트 위치), 변이 횟수 분포·자손 128·세대 50·생존 16/4/2·
  토큰 수 기준 단계 크기를 공식대로. 반복마다 부모는 중심(전부 0)에서 시작.
- **`make_slim.py`:** 새 supernet 형식에서 고른 수준을 읽는 경로. 어떤 층의 head나 MLP가 전부 제거되는 경우 처리.
- **NEURON 실행:** kd2 트리를 건드리지 않도록 이 트랙 전용 코드 사본(`/scratch/e1997a06/project/amc-tyr`, outputs는 공용 `/scratch/e1997a06/outputs`).
  supernet(반복당 약 41 GB)은 탐색 잡 시작 시 노드 로컬 `/tmp`(3.5 TB)로 복사해 후보마다 Lustre를 읽지 않게 한다.

## 4. 게이트
- **G0 (OSSCAR 일치):** 포트의 수준별 풀이와 공식 `LocalPruner.local_prune_core`를 같은 무작위 H·W에 돌려 결과가 일치하는지
  (head 묶음 128·1회, 채널 묶음 1·16회). CPU에서.
- **G1 (예산):** 반복마다 탐색 결과의 총 유지 수가 Q head 684 / MLP 채널 266,040, 즉 제거 2,657,452,032로 그대로인지.
- **G2 (스모크):** 블록 2개·클립 2개 supernet, 세대 2 탐색, R=2 재중심까지 한 번 돌려 형식·경로 확인.
- **G3 (빌드):** 최종 slim이 로드되고, 0인 열로부터 다시 얻은 유지 집합이 탐색 결과와 같은지. 클립 1개 rollout이 정상인지.

## 5. NEURON 일정·비용 (추정)
- 반복마다 4장 잡 하나: supernet(블록 순차, 약 1–1.5시간) → 탐색(4장 병렬, 약 1시간). `--dependency=afterok`로 R=1–4 연결
  (계정 제출 한도 4개 안). teacher 캐시(dense CoC·top-8,192 logits)는 R=1 잡 시작 시 한 번.
- 빌드 약 8–10시간, 약 18–25 A100-시간. 이후 slim 빌드(약 10분)와 A100 평가 큐 7개 작업(약 6 A100-시간, 4장으로 2시간 남짓).
- supernet 4회 × 약 41 GB = 약 164 GB /scratch(한도 100 TB), 파일 수 약 2,600개.
