# MoOP l0keep + 1–4번 층 MLP 추가 제거 폐루프: s600, 95 / 90 / 80% 세 판 (2026-10-30)

## 0. 목적

- **출발점.** A100 개루프(`cvpr27/reports/2026-10-30_l0keep-l14-mlp-cut.md`, 브랜치 `cvpr27-l0keep-l14-mlp`)에서 1–4번 층 MLP를 더 자른 세 판의 결과:
  - 주행: test_2000 Δ minADE@6이 MoOP l0keep 대비 +0.006 / +0.010 / +0.016 m로 작다.
  - LingoQA: −3.6 / −4.0 / −6.0 pp로 사전 등록 "공짜" 기준을 통과하지 못했다.
- **질문.** 개루프에서 거의 공짜였던 주행 비용이 폐루프에서도 작은가.
  - 개루프 "MLP 폭은 공짜" 판정은 폐루프에서 뒤집힌 전례가 있다(`dual+h4` −0.091).
  - 그래서 세 수준을 모두 재서 절단량에 따른 변화(용량-반응)를 본다.
- **사용자 결정 (2026-10-30).** 세 판을 모두 차례로(95 → 90 → 80) 돌린다.

## 2. 실행

- **스크립트:** `cvpr27/code/run_l14m_s600.sh`. 세 판을 차례로 돈다. 판마다 다음 순서다.
  1. GPU 8장이 모두 빌 때까지 기다린다. 첫 판은 CE-only 분석이 끝날 때까지도 기다린다.
  2. `run_dual_s600.sh STAGE=smoke`를 돌린다. 8씬, 카드당 1씬이다.
  3. smoke 게이트(`s600_smoke_gates.py`)를 본다. G1·G2 중 하나라도 실패하면 큐 전체를 멈춘다.
  4. `STAGE=main`으로 나머지 592씬을 돌리고, 병합 후 컨테이너와 네트워크를 정리한다.
  5. 짝 분석을 돌린다(§3).
- **설정:** 패치된 alpasim(인계 수정), `pair_a15`, `DRIVER_OMP_THREADS=8`.
  - 씬과 카드는 `outputs/alpasim_dual_s600/scenes_{smoke8,d600}.csv`의 `shard` 열을 따른다.
  - 모든 씬이 dense·출하본 MoOP와 같은 카드에서 돈다.
- **이름:** TAG `m95` / `m90` / `m80`. 런은 `alpasim-runs/m<XX>_merged_slim_dual_u40_l0keep_l14m<XX>_v2`, 결과는 `outputs/cvpr27/alpasim_l14m<XX>_s600/`.
- **시간:** 판당 약 7–7.5시간(8장). 세 판이면 약 22시간이다.
  - 10-30 22:20 KST쯤 시작하면 10-31 저녁 8시 전후에 끝난다.
