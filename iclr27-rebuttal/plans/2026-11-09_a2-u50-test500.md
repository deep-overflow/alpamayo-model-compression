# Plan: Alpamayo 2 Super at u50 on test500 — dense / MoOP / FM-only / CE-only

Status: done 2026-11-10 02:43 KST -> report `iclr27-rebuttal/reports/2026-11-10_a2-u50-test500.md` (user ask 2026-11-09, GPUs 0-3 allowed). Follows `2026-11-09_a2-moop-test500.md` (u40, done).

## Purpose
- Ask: how A2 holds up when the pruning ratio goes from u40 to u50, for MoOP, FM-only and CE-only against dense.
- Hypotheses to read off:
  - H1: the A2 cost grows with the ratio (u40 MoOP +11.8%).
  - H2: the u40 tie MoOP ≈ FM-only on driving persists or opens up at u50. At u40, MoOP − FM-only was +0.007 n.s.
  - H3: CE-only stays the worst arm and degenerates more at u50.

## Setup
- **Ratio.** `u50` is make_slim's literal 0.50 per layer for Q heads and MLP channels. u40 was the matched value 0.3985632694, not 0.40.
- **On A2.** Each layer cuts Q 32/64 and MLP 12,800/25,600. That is 238,551,040 params × 64 layers = 15,267,266,560 = 42.6% of 35.81B (u40 was 34.1%).
- **On A1.5, for reference.** u50 would be 30.0% of 11.08B (u40 was 24.0%).
- **Scores.** Same importance as u40 (`alpamayo2-distill/outputs/a2_importance_v1`, calib_100).
  - MoOP = max(rank I_traj, rank I_CoC)
  - FM-only = rank I_traj
  - CE-only = rank I_CoC
- **What is left alone.** No l0keep (not asked). Expert, KV, vision and embeddings are untouched.
- **Protocol.** Identical to u40: `run_a2_openloop.py`, 1 CoC rollout + k=8, minADE@6 / minFDE@6 at 1.6 / 3.2 / 6.4 s, the test500 manifest and the `test500_a2` cache.
- **Hardware.**
  - GPUs 4-7 are taken by another session, so the user allowed 0-3 (RTX PRO 5000 Blackwell).
  - Hardware moves results (A100↔Ada MoOP ±0.02 m), so dense is re-run on Blackwell and every u50 delta is against Blackwell dense.
  - All exp ids carry `_bw`. The Ada u40 rows are context only.
  - Two pairs: cards 0,1 run shard 0 and cards 2,3 run shard 1. Each pair runs `dense moop_u50 fm_only_u50 ce_only_u50` in order.

## Gates
- **G0.** `make_a2_moop_masks.py` still reproduces the four shipped A1.5 u40 kept sets unit for unit.
- **G0'.** Same function at literal ratios 0.20 / 0.30 on A1.5 importance_v2 reproduces `slim_dual_u20_v2` / `slim_dual_u30_v2` unit for unit. This checks the non-u40 ratio path.
- **G-ana.** The `--preset u40` analysis rerun reproduces the existing `a2_test500_analysis/metrics.json`.
- **Run check.** The first clips of `dense_bw` are finite and have EOS. Dense_bw − dense Ada gives the measured hardware shift.

  - `--pct N`: 40 = the old behaviour and files.
  - Any other value writes `masks_{moop,fm_only,ce_only}_u<N>.npz` and `masks_config_u<N>.json`.
  - G0' is added to the regression.
- `run_a2_arms.sh`:
  - `EXP_SUFFIX` is appended to every exp id.
  - `PLAN` is passed through.
  - The masks lookup is unchanged.
- `run_a2_openloop.py`: `--plan`, written to config.
- `analyze_a2_test500.py`:
  - `--preset u40|u50`. u50 rows are Blackwell, with Ada u40 as context.
  - Pairs:
    - each u50 arm − dense_bw
    - MoOP − FM-only
    - MoOP − CE-only
    - dense_bw − dense Ada (hardware shift)
