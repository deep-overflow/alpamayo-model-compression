## Arms

| arm | VLM | expert | note |
|---|---|---|---|
| A2 dense | original | original | reference |
| **A2 + MoOP (ICLR27)** | `max(rank_ℓ(I_traj), rank_ℓ(I_CoC))` within each layer, same uniform cut in **every** layer including layer 0 (no l0keep), Q heads + MLP channels only, KV groups kept | untouched | the paper's main MoOP row (`dual_u40_v2`) ported to A2 |
| (optional, D3) A2 + MoOP l0keep | same, layer 0's Q heads exempt, budget paid back from MLP | untouched | control for the layer-0 collapse risk |

- Last layer: `I_traj ≡ 0` there, so the rank-max reduces to `I_CoC`. This is the same behaviour as A1.5's shipped dual; `dualfix` was shown identical.
- Masks: 0/1 per Q head at the `o_proj` input and per MLP channel at the `down_proj` input of each VLM text layer. These are forward pre-hooks, the same placement as A1.5 `mask_lib` and the importance gates. Zeroing there equals removing the unit. No sliced checkpoint and no disk use.

## Budget (D1)

ICLR27 MoOP = remove 39.86% (0.3985632694) of the Q heads and MLP channels in every VLM layer.

| option | per layer, A2 | removed params | share of A2 (35.81B) |
|---|---|---|---|
| **(a) same per-layer ratio (recipe as defined)** | Q 26 of 64, MLP 10,203 of 25,600 | 12.21B | **34.1%** |
| (b) same share of the whole model as the paper (24%) | ratio ≈ 0.28: Q 18 of 64, MLP ≈ 7,200 | ≈ 8.6B | 24% |

The A2 text decoder is a larger part of the model than A1.5's, so the same per-layer cut removes a larger share.
For A1.5 the two options coincide (24.0%). Recommendation: (a), the recipe as written. Report (b) only if the user wants the paper's 24%.

## Data and protocol

- Cache: `build_cache_a2.py --manifest outputs/eval_sets/test_500.parquet --cache-name test500_a2 --old-cache-name test`.
  It is about 5 GB, streamed with the `full_right` token env.
  `--verify` checks that the ego tensors equal the A1.5 test cache, the same check as calib_a2.
- Runner: thin wrapper `iclr27-rebuttal/code/run_a2_openloop.py`. It imports `run_oodval` and changes three things:
  - manifest → test_500
  - cache → `test500_a2`
  - optional `--masks <npz>` installs the hooks
- Protocol: k=8, seed 42 per clip (`sha256(seed:clip_id)`), max_gen 256, the release CoC path, no teacher forcing.
- Readouts: minADE@6 / minFDE@6 at 1.6 / 3.2 / 6.4 s, medians, CoC degeneracy, buckets. Paired Δ (MoOP − dense) with bootstrap 200,000, Wilcoxon.
- Same GPU type for both arms (one table, not mixed with A1.5 rows). A1.5 test500 numbers are shown only as context.

## Gates

- G0 (masks): kept counts per layer as in D1. Rank-max reproduces an independent numpy recomputation. Layer-0 heads are listed.
- G1 (hooks): an all-ones mask gives outputs bitwise equal to the hook-free model on 3 clips. A MoOP mask changes the CoC NLL on those clips.
- G2 (cache): `--verify` passes for all 500 clips (ego tensors equal to the A1.5 test cache).
- G3 (smoke): dense on the first 5 clips: finite metrics and CoC ending in `<|traj_future_start|>`.

## Compute (D2)

A2 needs ~72 GB per replica (model card, H100), so each replica uses **two 48 GB cards**. At ~16.6 s/clip per pair:
- one arm × 500 clips ≈ 2.3 h per pair
- dense + MoOP on two pairs in parallel ≈ 2.3 h wall-clock, or ≈ 4.6 h on one pair
- the optional l0keep arm adds ≈ 2.3 h pair-time
- cache build ≈ 0.5–1 h, CPU and network

The session rule so far was "GPU 4 only". A2 cannot run on one card, so D2 needs the user.

## Risks

- **Layer-0 collapse:** in A1.5, which layer-0 Q heads the ICLR27 recipe cut decided cruise collapses (arm-to-arm SD 0.26–0.34 on test500).
  The A2 recipe cuts 26 of 64 layer-0 heads, so a single draw can land badly. That is why D3 exists.
- A single calibration draw (calib_100) and a single importance run: no seed spread on A2.
- Hardware: A2 on Ada pairs vs the A1.5 test500 rows on single Ada cards. This is not an issue inside the A2 table.
