# Plan: Alpamayo 2 Super u55-q8 (8 Q heads + 16,384 MLP channels per layer) — MoOP vs FM-only vs CE-only on driving

Status: pre-registered 2026-11-14 (before any u55-q8 clip was evaluated); running. User goal (/goal): "MoOP가 FM-only와 CE-only를
이길 때까지 해줘."

## Why this test (and what has been tried — every attempt stays in the record)

| attempt | result |
|---|---|
| u40 | driving MoOP = FM-only (3 sets), > CE-only; LingoQA val all n.s. |
| u50 | driving MoOP < FM-only (+0.109* / +0.077*), > CE-only; LingoQA val MoOP > both (+8.2* / +4.4*) |
| u50, LingoQA-train replication (pre-registered) | **not replicated**: MoOP − FM-only +1.8 pp (p_holm 0.11), MoOP − CE-only −1.5 pp |
| u50-q8 | driving MoOP vs FM-only −0.022 / −0.050 n.s.; vs CE-only −0.045 n.s. / −0.348* |

**Hypothesis H-dose.** MoOP's advantage over a single criterion appears only where that criterion breaks.

- **Evidence that the halves break before MoOP:** at u50-q8 on OOD-Val, CoC degeneracy was 0.8% for MoOP, 5.0% for FM-only and 12.6% for CE-only.
- **Why q8:** q8 removed MoOP's own head-driven loss.
- **Test:** keep the q8 allocation (8 Q heads cut per layer) and raise the budget one step, to u55.
- **Prediction:** both halves degrade faster than MoOP, so MoOP beats both on driving.

## Arms

- **Budget.** u55 per-layer budget = 35 heads + 14,080 channels = 262,144,000 params.
  - q8 keeps that exactly with 8 heads + 16,384 channels (64% of the MLP), using make_slim's `_qcut` rule.
  - Removed: 16,777,216,000 = 46.9% of A2.
- **Masks.** `masks_{moop,fm_only,ce_only}_u55_q8.npz` from `make_a2_moop_masks.py --pct 55 --q-cut 8`.
  - G0a: 7/7 A1.5 kept sets reproduce.
  - G0b: exact budget, nested with u55.
- **Arms run.** MoOP, FM-only and CE-only at u55-q8 on test500 and OOD-Val262, plus dense OOD-Val262.
  - test500 dense is the existing Blackwell run `a2_test500_dense_bw`.
  - The comparison does not need dense; it is context only.

## Protocol

- **Hardware and runner.** cvlab21 Blackwell 0-3 (2 pairs, one card type for the whole table); `run_a2_arms.sh` with `EXP_SUFFIX=_bw`, `SET=test500` then `oodval`.
- **Sampling.** The usual protocol: 1 CoC rollout + k=8, seed sha256(42:clip_id), max_gen 256.

## Primary test (fixed now)

- **Data and metric.** Pooled test500 + OOD-Val262 = 762 clips; metric minADE@6 at 6.4 s; paired per clip.
- **Hypotheses.**
  - H1: MoOP u55-q8 < FM-only u55-q8.
  - H2: MoOP u55-q8 < CE-only u55-q8.
- **Statistics.** Bootstrap over clips, 200,000 draws, two-sided p, Holm over {H1, H2}.
- **Confirmed** only if both Holm-adjusted p < 0.05 with negative deltas (MoOP better).
- **Also reported, no correction.** Each set separately; 1.6 / 3.2 s; minFDE@6; CoC degeneracy.
