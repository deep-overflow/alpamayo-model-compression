KI-LoRA 회복 학습: 붕괴한 dual_u55를 dual_u40 수준으로 (+ dual_u70 확장)

2026-08-20 · 계획서 plans/2026-08-19_recovery-training.md · 학습 run recover_dual_u55 (wandb kaist-cvlab/alpamayo-recovery/82340b2q) · 분석 outputs/recovery_eval/

헤드라인. 제로샷으로 붕괴 상태였던 dual_u55(VLM 33.1% 프루닝, 7.41B; test_500 minADE@6 4.26, CoC degeneracy 71%)가 4,800샘플 KI-LoRA 학습(GPU 4장 × 40분)만으로 dual_u40 제로샷(8.42B)과 세 평가 세트 모두에서 통계적으로 구분 불가한 수준까지 회복됐다 (Δ +0.03~+0.06, p=0.22–0.45). CoC degeneracy는 0.000으로 완전 소멸. 같은 품질에서 파라미터가 10억 개 더 줄었다 — 얕은 회복 학습이 한 단계 깊은 프루닝을 사실상 공짜로 만든다. 폐루프(alpasim 150 scenes)에서도 baseline을 +0.074로 유의하게 이기며 (dual_u40 +0.079와 동률), 세 게이트를 모두 통과했다.

u70 확장(§6). 같은 레시피를 −41.8%(6.44B)에 적용하면 격차의 93–97%가 회복되지만 (degeneracy 0.998→0.000), u40·u55와 동급은 아니다 — 세 세트 모두 유의한 잔여 열위(+0.18~+0.27)가 남는다. 회복이 프루닝을 무한정 상쇄하지는 못한다.

1. 배경과 가설

비율 스윕에서 uniform 40%(dual_u40_v2, −24% params)는 제로샷으로 성능이 유지됐지만 uniform 55%(dual_u55_v2, −33%)는 붕괴했다: test_500 minADE@6 4.2644(baseline 0.8417), CoC degeneracy 0.714. 단서는 ood_val에서 나왔다 — 제로샷 u55에 큐레이션된 CoC를 teacher-forcing하면 minADE가 3.57→1.42로 내려간다. 즉 손상의 대부분은 액션 헤드가 아니라 망가진 추론 문맥을 경유한다.

H1: 소량의 회복 학습으로 u55의 궤적·추론 붕괴가 대부분 회복된다. 특히 CoC 생성 (종료 토큰 포함)을 언어 공간에서 교정하면 궤적 지표가 함께 돌아올 것이다.

2. 방법: Knowledge Insulation LoRA

π0.5의 Knowledge Insulation을 LoRA에 적용했다. VLM forward 1회로 CoC logits과 KV cache를 얻고, cache를 detach한 뒤 expert가 flow-matching 스텝을 돈다:

  • CE → VLM LoRA만: teacher-forced CoC의 cross-entropy. cot_end/traj_future_start 토큰까지 타깃에 포함 — 폭주형 degeneracy(제때 종료 못함)를 직접 교정하는 지렛대.
  • FM → expert LoRA만: x_t=(1−t)·noise+t·x1, v_target=x1−noise (t~U(0,1)), detach된 cache 위에서만 backward. 궤적 gradient는 VLM에 닿지 않는다.
  • 절연은 시작 시 수치로 검증된다 (FM-only backward에서 VLM LoRA grad 전부 0, CE-only에서 expert LoRA grad 전부 0 — ki_check 게이트).

LoRA r=32/α=64, 살아남은 q/k/v/o+gate/up/down (VLM 36층 + expert 36층), 학습 파라미터 110.8M (1.5%). 학습 후 merge하면 체크포인트 형태·지연시간이 slim과 동일하다.

6. u70 확장 (−41.8%, 6.44B)

6.4 읽기: 회복에도 벽이 있다

  • 메커니즘은 재현된다. degeneracy 99.8%의 완전 붕괴도 150 step에 0으로 잡히고, GT-CoC NLL이 10.38→1.21로 정상화된다. "언어 채널 교정이 궤적을 끌어올린다"는 u55의 관찰이 더 깊은 손상에서도 성립한다.
  • 그러나 동급은 아니다. u70 recovered는 dual_u40 제로샷 대비 세 세트 모두 유의하게 열위(+0.18~+0.27)이고, u55 recovered보다도 +0.119 [+0.058, +0.179] 나쁘다. u55에서 성립했던 "회복하면 u40과 구분 불가"가 u70에서 깨진다 — −33%와 −41.8% 사이에 회복이 메우지 못하는 벽이 있다.
  • 새 트레이드오프 점. 1.72× 압축은 baseline 대비 minADE +0.29(+34%)를 요구한다. 1.50×(u55)가 +0.17로 u40급이었던 것과 대비된다. 벽의 정확한 위치는 u60~u65 탐색이 필요하다.

7. 해석 (의견)

  • 붕괴의 경로가 확인됐다. u55의 궤적 손상 대부분은 망가진 추론 문맥 경유였다 — CoC 생성만 언어 공간에서 교정하자 (KI라 궤적 gradient는 VLM에 닿지 않았는데도) 궤적 지표가 u40 수준으로 돌아왔다. expert 쪽 FM 적응은 보조적이었을 가능성이 높다.
  • 압축 프론티어의 이동. "u40까지는 공짜, u55부터 붕괴"였던 그림이 "u55도 4,800샘플 회복이면 u40과 동급"으로 바뀌었다. 보고 기준을 제로샷에서 회복-후로 옮기면 동일 품질에서 −1.0B를 더 벌 수 있다. 다만 이 이동은 무한하지 않다 — u70(§6)은 격차의 93–97%를 회복하고도 유의한 열위가 남으므로, 프론티어는 u55 부근에서 꺾인다.
  • baseline과의 격차는 남는다 (+0.10~+0.17, 유의). 33% 프루닝 모델의 잔여 비용으로, 회복이 프루닝을 무손실로 만들지는 않는다.

8. 한계

  • 단일 시드·단일 데이터 draw. 캘리브레이션-draw 연구(2026-08-19)에서 draw 하나가 +0.09를 움직인 전례가 있어, 회복 학습 데이터 draw의 분산도 미지수다.
  • dual_u40과의 비교는 u40 제로샷 기준이다. u40에 같은 회복 학습을 적용하면 더 좋아질 수 있다 (공정한 frontier 비교의 다음 단계).
  • "단순 파인튜닝 이득"과 "프루닝 손상 회복"의 분리를 위한 unpruned+동일레시피 대조군은 미실행.
  • u70은 폐루프(G3′)를 아직 돌리지 않았다. open-loop 열위가 실주행 점수로 이어지는지는 미확인이며, u55에서 open-loop 열위(+0.17)에도 폐루프가 baseline을 이겼던 전례가 있어 직접 측정이 필요하다.
  • u55는 600 step / probe K=1, u70은 1,200 step / probe best-of-6로 학습 설정이 완전히 동일하지는 않다 (probe는 선택에만 쓰이므로 보고 지표는 영향받지 않지만, 학습 길이 차이는 두 arm의 직접 비교에 남는 교란 요인이다).
  • ood_val 262는 커버리지가 좁고, official probe와 OOD gt_coc의 스타일 차이가 CE에 주는 영향은 분리하지 않았다.
