Head Pruning을 위한 Attention 분석 결과 (Phase A + B)

2026-07-20 · 모델 nvidia/Alpamayo-1.5-10B · calibration 50 clips · 코드 experiments/head_analysis/ (branch head-attention-analysis) · 산출물 outputs/head_analysis_v1/ · 계획: 2026-07-19_head-pruning-attention-analysis-plan.html

1.목적

승인된 분석 계획의 Phase A(attention 통계)와 Phase B(Taylor importance)를 실행하여 다음 가설을 검증했다.

  • Head importance는 균일하지 않으며, 낮은 importance의 head 집단(pruning 후보)이 존재한다.
  • VLM head와 expert head는 서로 다른 추론 단계(CoC 생성 vs trajectory denoising)에 기여하므로, 단계별 loss로 따로 평가해야 한다.
  • Expert가 VLM KV cache를 실제로 어떻게 사용하는지가 layer/KV pruning의 제약을 결정한다.

3.2 Phase A — VLM attention의 3-band 구조

  • Trajectory history token(48개)으로 가는 attention은 평균 2.7%로 작지만 특정 head(최대 45%)에 집중 — ego-motion 전담 head가 소수 존재한다.
  • 카메라별 CoC-query attention mass: cross-left 20.1%, front-wide 9.3%, front-tele 6.4%, cross-right 3.4%.
  • 중복성: 레이어 내 head output의 평균 off-diagonal CKA는 0.102로 낮으나, layer 35는 0.424로 눈에 띄게 높다 (최저는 layer 9의 0.038).

3.3 Phase A — Expert의 VLM cache 사용 패턴

  • Expert attention의 평균 72.6%가 cache의 vision token으로, 19.0%가 텍스트 영역으로 간다. 자신의 diffusion token 64개에는 3.5%만 배분된다 (마지막 layer 35에서만 12.4%로 상승).
  • FM-loss cache Taylor의 92.3%가 VLM layer 16–35 구간에 집중된다. Layer 0–15의 cache 기여는 합쳐서 7.7%.
  • Layer별 최대 기여는 layer 22 (8.6%), layer 21 (7.9%).

3.4 후속 검증 — 프롬프트 텍스트와 생성 CoC의 분리 보정

초판 보고서 정정: 위 3.3의 곡선에서 “text/CoC”로 표기한 영역은 프롬프트 텍스트와 생성된 CoC를 합친 값이었다. 두 영역의 토큰 수가 28배 차이 나기 때문에(프롬프트 텍스트 416개 vs CoC 약 15개, vision 2,880개) 이 곡선은 사실상 프롬프트 텍스트를 보여주고 있었다. 별도 실험(outputs/expert_per_clip_v1, 동일 50 clips)으로 두 영역을 분리 재측정했다.

4.Analysis (Opinion)

핵심 발견: (1) VLM attention은 기능적으로 뚜렷한 3-band 구조(text → sink → vision)를 가지며, sink 전담 head 181개가 layer 7–16에 몰려 있다. (2) Expert는 VLM cache의 vision token을 주로 소비하며, VLM layer 0–15의 cache는 trajectory 생성에 거의 기여하지 않는다 (7.7%). (3) Expert가 생성된 CoC에 배분하는 attention은 2.3%에 불과하다. (4) 하위 25% head가 전체 importance의 2–5%만 차지해 1차 pruning 여유가 상당하다.

Attention mass는 head 중요도의 대리 지표가 아니다

Expert head의 attention mass와 Taylor importance는 head 단위로 보면 상관이 높아 보이지만(mass_own vs Taylor, Spearman r = +0.705), 이는 layer 깊이라는 교란 변수 때문이다. Layer index는 Taylor(r = +0.853)와 attention mass(r = +0.932) 양쪽 모두와 강하게 상관된다. 같은 layer 내부로 한정하면 관계가 무너진다.

결정적으로 각 layer에서 attention이 가장 큰 head가 실제 Taylor 최상위 head인 경우는 36개 중 2개뿐이었다(vision mass 기준). Softmax는 합을 1로 강제하므로 할 일이 없는 head도 질량을 어딘가에 버려야 하고(sink 현상), 반대로 분산된 attention도 value·o_proj를 거쳐 큰 기여를 낼 수 있다. Attention은 “어디를 보는가”를 알려줄 뿐 “출력을 얼마나 바꾸는가”를 알려주지 않는다. 따라서 Phase A는 해석용, Phase B(Taylor)는 pruning 순위 결정용으로 역할을 분리해야 한다.

  • Q-head pruning 여유: 하위 25% VLM Q head(288개)가 importance의 4.9%, 하위 25% expert Q head(144개)가 2.4%만 차지한다. Taylor 1차 근사가 ablation과 일치한다면(Phase C에서 확인) 이 구간은 낮은 위험으로 제거 가능하다. Q-head pruning은 KV cache 구조를 건드리지 않으므로 cross-model 제약도 없다.
  • Sink band(layer 7–16)의 해석: sink 전담 head는 “attention을 주차”하는 역할로 알려져 있어 출력 기여가 작을 가능성이 높다. 다만 sink head 제거는 softmax 질량 재배분을 일으켜 다른 head의 분포를 바꿀 수 있으므로, ablation 검증에서 이 band를 별도 그룹으로 다뤄야 한다.
  • Layer-pair pruning 관점: expert가 layer 0–15 cache를 거의 쓰지 않는다는 것은, 이 구간에서 (VLM layer, expert layer) pair 제거 시 expert 쪽 손실은 작을 것임을 시사한다. 반대로 layer 20–22, 26, 30–35의 cache는 expert에 필수적이다. 단, VLM 쪽 CoC 품질 손실은 별개 문제다 — CoC용 Q-head importance는 layer 18–24가 최고라 두 신호가 겹치는 후반부는 pair로도 제거 불가.
  • Layer 35의 이중성: expert Q-head importance 최상위가 layer 35이고, 이 layer에서만 diffusion token 자기-attention이 커진다(12.4%) — 최종 layer는 action 출력 직전의 정보 통합을 담당한다. 반면 VLM 쪽 layer 35는 head 간 CKA 0.42로 중복이 커서 VLM Q-head는 여기서 줄일 여지가 있다.
  • CoC의 역할에 대한 재해석: expert가 생성된 CoC에 쓰는 attention은 총 2.3%지만, token 하나당으로는 vision보다 8–10배 높다. 즉 CoC token은 “개별적으로는 밀도 높은 정보”이되 개수가 적어 총량이 작다. 두 해석이 가능하다 — (a) CoC가 압축된 형태로 trajectory에 영향을 주거나, (b) CoC의 영향이 attention 경로가 아니라 VLM이 CoC를 생성하는 과정에서 cache 자체가 갱신된 것을 통해 간접 전달된다. 후자라면 CoC의 가치는 expert의 CoC-attention 크기로 측정할 수 없다. Phase C에서 CoC 구간을 마스킹한 denoising으로 구분 검증할 필요가 있다.
  • 한계: (1) Taylor는 1차 근사이며 head 간 상호작용(동시 제거 효과)을 반영하지 못한다. (2) KV-head의 CoC 측 점수는 v-gate만 반영하고 k 경로는 제외했다. (3) calibration 50 clips는 주행 시나리오 분포를 제한적으로 커버한다.

다음 단계 (Phase C)

  1. Taylor ranking 하위 10/25/50% Q-head를 실제 마스킹하고 held-out 12 clips에서 minADE / CoC NLL 곡선 측정.
  2. KV-group 단위 ablation(288회)으로 Taylor 순위와 Spearman 상관 확인.
  3. Sink band(layer 7–16)를 별도 그룹으로 ablation하여 질량 재배분 효과 검증.
  4. CoC 구간을 마스킹한 denoising으로 CoC가 trajectory에 미치는 실제 인과적 기여 측정 (attention 경로 vs cache 갱신 경로 구분).
