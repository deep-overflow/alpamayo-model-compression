강화된 평가 — Multi-sample minADE와 시나리오 층화

2026-07-22 · 모델 nvidia/Alpamayo-1.5-10B · 평가 50 clips (val), K=8 samples · 코드 experiments/head_analysis/{eval_lib,run_eval,analyze_eval}.py · 산출물 outputs/eval_val_k8/ · 계획: 2026-07-22_eval-protocol-plan.html
2026-07-22 정정 (KV group). 본 보고서의 KV group 제거 결과는 VLM 쪽 Q head(4개/group)만 마스킹한 것으로, expert는 해당 group의 cache를 계속 읽고 있었다. 물리적 group 제거와 동등한 충실한 ablation(양 tower의 Q head 동시 마스킹, outputs/kvfix_*)을 추가로 수행한 결과 group 1개 제거도 실제 regression(+0.079, CI [+0.002, +0.151])이며, 비용의 대부분은 expert의 cache 접근 상실(+0.053)에서 온다. 따라서 “KV cache −12.5% 무료” 주장은 철회한다. 본 보고서에서 유효하게 남는 결과는 “trajectory 기준으로 고른 VLM 쪽 Q head 4개/layer 제거는 무료”이며, 이는 cache 절감이 없는 Q head pruning이다. 상세: 2026-07-22_compression-comprehensive-report.html §7.

1.목적

P2의 평가는 세 가지 결함이 있었다: 단일 샘플(num_traj_samples=1), 평균만 봄, 지표 하나(minADE). 승인된 계획에 따라 이를 강화하고, P2의 “무료” 주장이 더 엄밀한 평가에서도 유지되는지 검정한다.

  • Multi-sample minADE/minFDE (K=8). 공유 VLM prefill 위에서 seed만 바꿔 8회 denoise, 샘플 최소를 취함. baseline과 pruned가 동일 seed를 써 sampling 노이즈를 paired 상쇄.
  • 분포·최악 사례. 클립별 ΔminADE의 p50/p90/p95, paired bootstrap 95% CI, regression(>0.5m) 클립 수.
  • 시나리오 층화. 라벨이 없어 GT 궤적 기하에서 {직진, 회전, 감속·정지, 가속}을 파생하고 버킷별 악화를 본다.

K=1에서 K=8로 가면 baseline minADE가 1.736 → 0.657m로 떨어진다. P2가 measure한 것은 사실상 단일 표본 ADE였고, 아래에서 보듯 그 노이즈가 실제 결론 하나를 가리고 있었다.

버킷 분포: 직진 30, 회전 3, 감속·정지 12, 가속 5. 회전·가속은 표본이 적어 해당 버킷 수치는 신호로만 취급한다(결론 아님).

P2 결론이 뒤집혔다. P2(K=1)에서 trajectory vs CoC 기준은 “대체로 무승부”였다. K=8에서는 전체 layer 30% pruning에서 trajectory는 noise 범위(+0.017, CI가 0 포함)인 반면 CoC는 명백한 regression(+0.518, CI [+0.278,+0.794], 50 클립 중 19개가 0.5m 이상 악화)이다. 단일 샘플 노이즈가 이 차이를 가리고 있었다. 즉 강화된 평가는 엄밀성만 더한 게 아니라 “cache 기준이 output 기준보다 낫다”는 주장을 공격적 압축 구간에서 되살렸다.

2.3 시나리오 층화 — 평균이 숨긴 최악 사례

이것이 강화된 평가를 설계한 이유다. kv_traj_drop1은 평균 ΔminADE가 +0.021로 noise 범위지만, 버킷을 나누면 직진 +0.014인 반면 회전에서 +0.233이다. kv_traj_drop2는 회전에서 +0.431, kv_coc_drop1은 회전에서 +0.295다. KV cache를 줄이면 회전 궤적이 선택적으로 손상된다. 평균만 봤다면 “KV group 제거는 무료”로 결론 냈을 것이다.

단, 회전 버킷은 n=3으로 표본이 작다. 이 효과는 확정 결론이 아니라 확인이 필요한 강한 신호다. 회전 클립을 늘린 재측정이 P3의 후속 과제다.

2.4 유지된 “무료” 주장

  • drop_last_layer: 완전 무료. K=8, 모든 버킷, p95까지 정확히 Δ=0. CoC NLL만 +0.943. P1(구조적 0)과 P2(K=1)에 이어 세 번째 독립 확인이다.
  • 후반 layer pruning: 유지. traj/coc 30–50% 모두 CI가 0을 포함하고 regression 0개, p95 ≤ 0.29m. 버킷별로도 큰 악화 없음.
  • 전체 layer 20–30% (trajectory): 유지. CI가 0을 포함. 단 p95가 0.28–0.36m로, “무료”가 “최악 사례도 0”을 뜻하지는 않는다.

3.분석 (해석)

3.1 강화된 평가가 결론을 바꾼 두 지점

  1. Trajectory 기준의 우위가 드러났다. P2의 “무승부”는 부분적으로 측정 아티팩트였다. 공격적 압축(전체 30%)에서 trajectory Taylor는 무료, CoC Taylor는 19/50 클립을 망가뜨린다. 이는 “pruning이 보존해야 할 것은 출력이 아니라 expert가 읽는 cache”라는 본 연구의 핵심 주장을 채널 수준에서도 뒷받침한다 — P2에서 채널 수준 주장이 무승부였던 것과 대비된다.
  2. KV cache 축소의 숨은 비용이 드러났다. 평균으로는 무료인 KV group 제거가 회전에서 선택적으로 손상을 준다. KV cache 12.5% 절감이 배치 처리에 매력적이었지만, 이 축은 안전 관련 상황에서 대가가 있을 수 있다.

3.3 남은 한계

  • 회전·가속 버킷 표본 부족(n=3, n=5). 이 버킷의 수치는 신호이지 결론이 아니다. 회전 클립을 늘린 재측정이 필요하다.
  • 여전히 open-loop. 시뮬레이터·지도가 없어 closed-loop과 충돌 지표는 불가능하다. 이는 공개 데이터의 한계다.
  • val split, 최종 아님. test split(150)에서의 확정 수치는 아직 산출하지 않았다(오염 방지).
  • 마스킹은 실제 제거의 상한 성능이며, 결합 config는 미측정이다(P3 후속).

4.다음 단계

  1. 회전 버킷 재측정. KV group의 회전 손상 신호를 회전 클립 수를 늘려 확인.
  2. 결합 config 실측. drop_last_layer + 후반 50% + 전체 20% + KV(회전 확인 후)를 동시 적용.
  3. LoRA 복구(P3 본편). 결합 config에 복구 학습을 적용해 마스킹 하한을 상한으로.
  4. test split 확정 수치.
