CoC + Trajectory 동시 유지 시나리오 — reasoning의 가격

2026-07-22 정정 (KV group). 본 보고서의 KV group 제거 결과는 VLM 쪽 Q head(4개/group)만 마스킹한 것으로, expert는 해당 group의 cache를 계속 읽고 있었다. 물리적 group 제거와 동등한 충실한 ablation(양 tower의 Q head 동시 마스킹, outputs/kvfix_*)을 추가로 수행한 결과 group 1개 제거도 실제 regression(+0.079, CI [+0.002, +0.151])이며, 비용의 대부분은 expert의 cache 접근 상실(+0.053)에서 온다. 따라서 “KV cache −12.5% 무료” 주장은 철회한다. 본 보고서에서 유효하게 남는 결과는 “trajectory 기준으로 고른 VLM 쪽 Q head 4개/layer 제거는 무료”이며, 이는 cache 절감이 없는 Q head pruning이다. 상세: 2026-07-22_compression-comprehensive-report.html §7.
2026-07-23 정정 (파라미터 정밀 재계산). 종전 KPI(−1.93B/17.4%, −3.20B/28.9%, 가격 1.27B)는 KV1이 추가로 끄는 Q head 수를 어림값으로 계상한 것이었다. 실험에 실제 사용된 마스크로 정확히 세면 KV1의 4 head/layer(총 144개) 중 width 선택과 중첩되지 않는 head가 dual_r20에서 87개, integrated에서 35개다. 정확값: cocsafe_full_r20 −2.01B(18.1%), integrated_mag −3.25B(29.3%), reasoning 가격 1.24B(11.2%p). 아래 표와 KPI는 정확값 기준이다.
2026-07-23 정정 (latency 실측 — 예상 속도 열 반증). 표의 “예상 속도” 열은 bandwidth-bound 가정 기반 추정인데, cocsafe_full_r20을 실제 가중치 절단으로 변환해 실측한 결과(2026-07-23_physical-removal-latency.html) end-to-end 0.96×(경로 통제 비교 1.02×)로 예측 1.22×가 반증되었다. decode·expert는 batch 1에서 dispatch-bound라 가중치 절감이 시간으로 전환되지 않는다. 실현된 이득: peak 메모리 −18%(21.5 → 17.7GB), prefill −4%. 열 값은 dispatch가 상각되는 환경의 잠재 상한 추정이었는데, 후속 CUDA-graph 실측(2026-07-23)에서 cocsafe_full_r20은 1.43×(986ms)로 확인되어 추정 1.22×를 상회한다 (2026-07-23_dispatch-optimized-latency.html). 품질 수치는 masked≡removed 동등성 확인으로 물리 제거에도 그대로 유효하다.

1.목적

trajectory 전용 config는 CoC를 희생하고(ΔNLL +2.86) 29.3%를 얻었다. 이번 실험은 두 능력을 모두 유지할 때의 압축 상한을 측정한다.

  • 선택 기준: layer 내 rank 정규화 후 score = max(rank_traj, rank_coc)의 하위부터 pruning — 양쪽 모두에서 하위인 단위만 제거된다. Layer 35 제거와 후반 감쇄(CoC 전용 용량 파괴)는 제외.
  • 유지의 작업 정의: ΔminADE의 CI가 0을 포함하고 ΔNLL ≤ +0.05 (baseline 0.21의 ~24%).
  • 대조군: 같은 30%를 단일 기준으로 자른 traj_r30 / coc_r30 — 각각 반대쪽 지표가 무너져야 dual 설계가 정당화된다.
  • Expert config(−0.60B)는 CoC gradient가 구조적으로 0이므로 이 시나리오에도 그대로 포함된다.

pruning 대상 표기. V = VLM self-attn Q head(q_proj 행 + o_proj 열) & MLP channel(gate/up/down), 36 layer 전체, layer별 하위 r% — 선택 점수만 다르다(dual = max(rank_traj, rank_coc), traj/coc = 단일 기준). K = layer별 최약 KV group 1개의 VLM 쪽 Q head 4개 추가 마스킹(dual KV score; k/v projection과 KV cache는 유지 — 상단 정정 참조). 4개 중 V 선택과 중첩되지 않는 head만 제거분에 가산된다(dual_r20 기준 87/144개, +0.09B). E = expert Q head & MLP channel, early(0–21) 40% / late(22–35) 10%, weight magnitude 기준 (−0.60B). Expert는 CoC gradient가 구조적으로 0이므로 dual 기준 불필요.

예상 속도(end-to-end 배속) 산정. Blackwell 실측 stage 프로파일(1,336ms = ViT 133 + prefill 265 + decode 508 + expert 378 + overhead 54) 위에서, prefill은 compute-bound라 잔여 VLM LM 가중치(6.95B 기준)에 비례, decode/expert denoise는 bandwidth-bound라 토큰/스텝당 읽는 가중치 바이트에 비례(decode 기준량 7.79B = LM 6.95 + lm_head 0.62 + KV cache 0.22 — lm_head와 cache는 줄지 않음), ViT/overhead는 불변으로 스케일한 추정치다. 마스킹 자체는 속도 이득이 없다 — 물리적 제거(실제 가중치 삭제)를 전제한 값이다. 2026-07-23 실측에서 이 모델의 decode/expert bandwidth-bound 가정이 반증되었으므로(상단 정정), 이 열은 dispatch 상각 환경의 상한 추정으로만 유효하다.

2.1 대조군이 설계를 검증했다

예측대로 단일 기준은 반대쪽 지표를 무너뜨렸다: traj_r30은 NLL +0.165(임계 3.3배), coc_r30은 ADE +0.488. dual 기준만이 20%에서 양쪽을 동시에 지켰다.

2.2 상한은 20%다 — 그리고 붕괴가 흥미롭다

dual_r30의 붕괴는 NLL이 아니라 ADE에서 왔다. 30% 예산에서 dual 기준은 CoC 중요 단위를 보호해야 하므로, 같은 layer 예산 안에서 trajectory 중요 단위를 더 깊이 잘라 들어간다(traj_r30은 같은 30%에서 ADE 무료였다). 즉 20%를 넘는 순간 두 목적이 같은 예산을 두고 경쟁하며, “양쪽 모두에서 하위”인 교집합이 소진된다. P1에서 본 후반 layer의 랭킹 분기(ρ≈0.28)가 정확히 이 지점에서 비용으로 돌아온다.

이로써 두 시나리오의 대비가 완성된다: reasoning(CoC)을 유지하는 데 드는 비용은 압축 가능량의 11.2%p(1.24B 파라미터)다. 이 1.24B가 곧 “Alpamayo에서 reasoning 능력이 점유하는, action에는 불필요한 용량”의 실측 하한이다.

표의 제거량 열이 드러내는 대비 하나: dual_r30(2.008B)과 cocsafe_full_r20(2.006B)은 사실상 같은 예산인데, 전자를 VLM에 몰아넣으면 ADE가 붕괴하고(+0.247*) 후자처럼 VLM 20% + expert로 나누면 양쪽이 유지된다. 같은 파라미터 예산이라도 어디서 빼느냐가 결과를 가른다.

3.분석 (해석)

  • 정직한 명시: dual_r20의 ΔNLL +0.012도 CI는 0을 배제한다 — CoC가 통계적으로는 미세하게 열화된다. “유지”는 작업 정의(+0.05 이내)에 대한 것이지 문자 그대로의 무변화가 아니다. 생성 CoC 텍스트의 질적 비교는 하지 않았다.
  • 회전 канary 재확인: dual_r30의 회전 +0.281, cocsafe_full_r30의 회전 +0.473 — 한계를 넘는 순간 이번에도 회전이 먼저 무너졌다.
  • P1→여기까지의 일관성: 랭킹이 겹치는 초·중반 layer 덕에 20%의 교집합이 존재하고, 랭킹이 갈리는 후반 layer 때문에 30%에서 경쟁이 시작된다. P1의 상관 구조가 압축 상한을 정량적으로 예측한 셈이다.
