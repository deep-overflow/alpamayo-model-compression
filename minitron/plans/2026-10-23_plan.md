## 0. 목적

Minitron(Sreenivas et al., *LLM Pruning and Distillation in Practice: The Minitron
Approach*, arXiv 2408.11796; 방법 세부는 선행 논문 Muralidharan et al., arXiv 2407.14679)을
Alpamayo 1.5 10B에 **외부 베이스라인으로 충실하게 재현**한다. 기존 연구 트랙의 확장이 아니며,
재현 원칙은 하나다:

- **논문에 답이 있으면 논문대로** 한다 (§2).
- **VLA 구조 때문에 논문에 답이 없는 곳만** 바꾸고, 각 변경은 사용자와 합의한 뒤 코드에
  `PORT:` 주석으로 남긴다 (LLM-Pruner 포트와 같은 관례). §3이 그 목록이다.

산출물은 논문 표에 들어갈 Minitron 행(프루닝만 / 프루닝+증류)과, 그것을 공정하게 읽기 위한
비교 설계(§4)다.

## 2. 논문 그대로 옮기는 것 (논의 불필요, 이견 있으면 지적)

1. 중요도: 활성 기반, gradient·rollout·GT 불필요, 1,024 샘플, (batch=L2, seq=mean), single-shot.
   **공식 고정 (2026-10-24, NVIDIA ModelOpt `modelopt/torch/prune/importance_hooks/base_hooks.py` 대조):**
   `L2NormHook`은 모듈 **입력**을 float32로 바꿔 `abs()` → 시퀀스 평균 → 제곱 → 배치(샘플) 합을 누적하고
   마지막에 제곱근 — 절댓값이 평균보다 먼저라 SwiGLU 활성의 부호 상쇄가 없다. 적용: MLP 채널 = `down_proj`
   입력의 이 점수(층별). hidden 채널 = 텍스트 탑의 모든 RMSNorm **출력**(층마다 input / post-attention 2개 +
   최종 norm, 73개)에 같은 집계를 하고 합산(2407: "층 점수는 층 합산"). head는 자르지 않으므로 재지 않는다.
2. Width 변형: **Q head와 KV group 전부 유지**, hidden 채널 + MLP 채널만 축소, 층 수 유지.
   hidden 유지 집합은 residual stream 하나이므로 **전 층 공통 1개**.
3. 증류: 순방향 KL, τ=1, **전체 어휘 logit**(top-K 근사 금지 → teacher를 학습 중 온라인으로
   돌린다), GT CE 미사용, **전체 파라미터** 학습, AdamW, peak 1e-4 → min 1e-5 cosine,
   warmup 40 step.
4. Depth 변형(채택 시): 연속 블록, 다운스트림 지표로 선택.

## 3. VLA 적용 시 논의할 결정 (D1–D11)

> **2026-10-23 문헌 조사 후 추천 변경** — 근거는 `minitron/plans/2026-10-23_literature.md` §0–1.
> - D1 비교 지점: (ii) → (i) GT 보간점, t는 추론 격자 균등.
> - D3: end-to-end → stop-gradient (Alpamayo-R1 자체가 KV 캐시 stop-gradient로 학습됨).
> - D2: 이산 궤적 토큰 위치 KL을 선택지로 추가.
> - D5: KV-only → 두 탑에서 짝 층 함께 제거.
> - D8: W-b → W-a.
> - D11: 무작위 선택 + 같은 KD 대조군 추가.
>
> 아래 본문의 "추천"은 변경 전 기록이다.

**궤적 토큰 문맥을 GT로 할 때의 문제 (2026-10-24 측정).** `coc_train.parquet`의 teacher CoC 머리 어절을
`coc_action_consistency.HEAD2BUCKET`으로 버킷화해 GT 버킷(`recovery_sets/bucket_pool_full.parquet`)과
비교. 매핑 가능한 머리 어절 45.6%(53,529개) 중:

| | 값 |
|---|---|
| 버킷 일치 / 불일치 | 55.8% / **44.2%** |
| 방향이 정반대인 명확한 모순 (CoC 감속·정지 ↔ GT 유지·가속 20.4%, CoC 가속 ↔ GT 정지 0.4%) | **20.8%** |
| teacher rollout minADE ≤ 1.0 인 샘플만 | 불일치 32.6% |
| teacher rollout minADE 중앙값 (일치 / 불일치) | 0.896 / 1.595 — 어긋날 때 teacher 궤적도 GT에서 멀다 |
| CoC가 감속·정지를 말하는 비율 vs GT 감속·정지 비율 | 46.9% vs 20.6% |

한계: 버킷은 6.4초 전체의 거친 분류라 일부 불일치는 표현 단위 차이(예: 회전 전 감속)다. 실제 모순 비율은
20.8%와 44.2% 사이로 본다. 같은 문제가 D1-2(GT 보간점)에도 적용된다 — expert는 teacher CoC로 만든
캐시를 읽는데 질의점은 GT 쪽으로 간다.

영향 범위: CoC 위치 텍스트 KL은 영향 없음(문맥에 궤적이 없음). 궤적 토큰 KL과 expert 속도 KD만 영향.
GT는 두 곳 모두 입력(질의점·문맥)으로만 쓰이고 정답은 항상 teacher 출력이므로, 어긋남의 비용은
정확성이 아니라 관련성이다.

**해결 후보 — 클립별 시점(window) 선택 규칙 (2026-10-24 측정).** 증류 데이터는 9,917 클립 × 클립당
중앙값 12 시점. 클립당 1 시점을 쓰므로 규칙을 만족하는 시점 중에서 고른다.

| 규칙 | 남는 시점 | ≥1 시점 남는 클립 | 클립당 1개 고른 GT 구성 (cruise / decel_stop / accel / turn) |
|---|---:|---:|---|
| R0 전부 | 100% | 9,917 (100%) | 0.54 / 0.12 / 0.17 / 0.17 |
| R1 명확한 반대 방향 제거 | 90.5% | 9,905 (99.9%) | 0.51 / 0.14 / 0.14 / 0.21 |
| R2 R1 + teacher rollout minADE ≤ 1.0 | 33.3% | 8,503 (85.7%) | 0.52 / 0.20 / 0.10 / 0.17 |
| R3 머리 어절이 매핑되고 일치하는 것만 | 25.4% | 6,248 (63.0%) | 0.41 / 0.31 / 0.16 / 0.11 |
| R4 R3 + minADE ≤ 1.0 | 13.7% | 4,711 (47.5%) | 0.44 / 0.36 / 0.11 / 0.09 |

R1은 클립·구성을 거의 그대로 두고 확인 가능한 모순만 없앤다. R2는 teacher가 GT를 잘 맞춘 시점만
남겨 "teacher가 틀리는 어려운 시점"을 빼는 선택 편향이 있다. R3·R4는 클립 37–52%를 잃고
decel_stop으로 치우친다. 머리 어절이 매핑되지 않는 54%의 CoC는 어떤 규칙으로도 검사되지 않는다.

KI 결정에 따른 구현 조건:
- 기울기 클리핑은 **탑별로 따로**(전체를 묶어 클리핑하면 두 탑이 다시 엮인다).
- 균형 조절이 필요하면 손실 가중이 아니라 **VLM / expert 학습률을 따로** 준다(기본은 둘 다 Minitron peak 1e-4).
- VLM은 action 신호를 받지 않으므로 D2의 이산 궤적 토큰 KL이 VLM에 action 정보를 주는 유일한 logit 경로가 된다. 이 KL은 텍스트 KL과 같은 단위·같은 파라미터이므로 별도 가중 없이 지도 대상 토큰 전체에서 평균한다.
- 기존 인프라: `experiments/recovery/recover_lib.py`의 `detach_cache_` / `fm_loss_insulated`와 `train_recover.py`의 `ki_check`(VLM 기울기 0 검증)를 그대로 쓴다.

Alpamayo는 LM 하나가 아니라 **VLM(텍스트 4096 hidden, 36층) + action expert(2048 hidden,
36층)** 두 탑이고, expert의 층 l은 VLM 층 l의 KV 캐시(8 group × 128)를 읽는다. 출력도
CoC 텍스트(logit)와 연속 action(flow-matching velocity) 두 개다. 아래는 그 차이 때문에
Minitron이 답을 주지 않거나, 답은 있지만 대상·규모가 달라 정해야 하는 항목이다.

### A. 구조상 Minitron에 답이 없는 것

**D1. action 출력을 증류할 것인가, 어떻게.** Minitron은 LM logit만 증류한다. 그대로 하면
expert(그리고 그것이 읽는 캐시)는 직접 신호를 받지 못한다.

| 선택지 | 내용 |
|---|---|
| (a) logit만 | 문자 그대로의 재현. action 채널 회복은 VLM 쪽 변화에 간접적으로만 의존 |
| (b) logit + velocity KD | 같은 (x_t, t, noise)에서 student/teacher velocity의 MSE. 분산 고정 가우시안 출력의 KL은 MSE에 비례하므로 "출력 KL"의 연속 출력판 |
| (c) (b) + GT flow-matching | Minitron은 GT 손실을 의도적으로 뺐다(2407: logit-only가 CLM 추가보다 좋음) |

추천 (b). 딸린 결정 둘: **가중** — 2407의 동적 규칙 α = L_logit / L_v(두 항 기여를 같게)
vs 고정 1. **t 분포** — 릴리스 코드에는 학습용 t 샘플러가 없다(`flow_matching.py`는 추론 Euler만).
U(0,1) vs 추론 격자(10 스텝 시점). 추천: 동적 α, U(0,1).

**D2. logit KL을 어느 위치에, 어떤 텍스트 위에서.** Minitron은 사전학습 텍스트 전 위치에
KL을 건다. Alpamayo 프롬프트는 3,086 토큰(실측, 고정)이고 대부분 vision 토큰이라 그 위치의
다음 토큰 분포는 의미가 없다. 생성 텍스트는 CoC(수십 토큰)와 종료 토큰이다.

| 선택지 | 내용 |
|---|---|
| (a) CoC + 종료 토큰 위치만, 문맥 = teacher가 생성한 CoC | 이미 있는 teacher 생성 CoC 사용 (`coc_generated/train/coc_train.parquet`, 119,260 샘플 / 10,040 클립). teacher 출력 위 teacher forcing |
| (b) (a) + 프롬프트의 텍스트 토큰 위치 | 지시문 텍스트는 고정이라 정보가 거의 없음 |
| (c) 문맥 = student 자신의 rollout (on-policy KD) | 생성 비용이 매 step 추가, Minitron에는 없는 요소 |

추천 (a).

**D3. 기울기 경로.** Minitron은 모델 전체를 손실 하나로 학습한다. Alpamayo에서는 velocity KD의
기울기가 KV 캐시를 거쳐 VLM으로 흘러갈 수 있다. π0.5식 지식 절연(KI: 캐시 detach, action
기울기는 expert에만)은 **Minitron에 없는 요소**다.
추천: **end-to-end(절연 없음)** — 원 방법이 단일 손실·전체 학습이므로.

**D4. hidden 채널 축의 경계.** residual stream 채널을 자르면 다음을 함께 잘라야 한다:
`embed_tokens`(155,697×4096, 궤적 토큰 포함 — untied), `lm_head`, 모든 RMSNorm 가중치,
q/k/v/gate/up의 입력 열, o/down의 출력 행, 최종 norm, 그리고 **vision 쪽 출력 경계** —
`visual.merger.linear_fc2`와 deepstack merger 3개의 `linear_fc2` 출력 행(시각 특징이
residual에 직접 더해지는 곳). k/v_proj의 **출력** 폭(8×128)은 그대로라 expert가 읽는 캐시
인터페이스는 깨지지 않는다. 논의할 것 두 가지:

- vision merger 출력 행을 자르는 것(= ViT 본체는 그대로, 경계 투영만 축소)을 받아들일지.
  hidden 축을 쓰려면 사실상 필수다.
- RMSNorm 분모가 남은 채널 평균으로 바뀌는 문제. Minitron은 보정하지 않고 증류에 맡긴다.
  추천: 보정 없음(원 방법대로).

**D5. depth 변형과 expert 캐시 인터페이스.** VLM 층을 지우면 그 층 번호의 캐시를 읽는 expert
층이 입력을 잃는다.

| 선택지 | 내용 | 24% 예산에서 |
|---|---|---|
| (a) Width만 | 2408의 권장(정확도 우위) | — |
| (b) VLM 층을 "KV-only"로 | q/o/MLP 제거, input norm + k/v 투영만 남겨 캐시 생산 유지 (`slim_lib.make_kvonly` 기존 구현). VLM만 건드림 | 층당 184,553,600 → 14층 2,583,750,400 (23.3%, −2.8%) / 15층 (25.0%, +4.2%) |
| (c) 층 l을 두 탑에서 함께 제거 | 진짜 제거, expert도 바뀜 (VLM-only 행과 비교 불가) | 층당 ~256M |

블록 선택 지표(Winogrande의 대응물)도 정해야 한다: probe 세트 minADE@6 vs CoC 지표 vs 둘의 조합.
추천: (a)를 주 arm, 지연시간 주장이 필요하면 (b)를 2차 arm으로. Minitron의 속도 이득은 depth에서
나오므로(2.7× vs 1.8×) "Minitron은 빠르다"는 비교를 하려면 (b)가 필요하다.

**D6. teacher correction의 라벨.** Minitron은 사전학습 라벨(다음 토큰)로 teacher를 고친다.
Alpamayo에서 증류 데이터(PhysicalAI-AV official train)에 있는 라벨은 GT 궤적뿐이고, CoC
라벨은 OOD train 1,271개(사람 큐레이션)뿐이다 — official train의 CoC는 teacher 자신의 생성이라
correction 라벨이 될 수 없다. 또 원 학습 데이터와 증류 데이터의 관계 자체가 공개돼 있지 않다.

| 선택지 | 내용 |
|---|---|
| (a) 생략 | teacher = 릴리스 모델 = 논문의 dense 행. 비교 기준점이 흔들리지 않음 |
| (b) GT FM(+가능한 CoC CE)로 짧게 correction, 게이트 통과 시 사용 | held-out 손실이 Minitron 수준(수 %)으로 내려가면 채택 |

추천 (a) 주 실험, (b)는 ablation. 근거: correction된 teacher는 dense 행과 다른 모델이 되어
"프루닝+증류가 dense 대비 얼마"라는 읽기가 두 요인을 섞는다.

### C. 비교 설계

**D11. MoOP에도 같은 증류를 붙일 것인가.** 논문의 MoOP 행은 zero-shot이고 Minitron 행은
재학습을 포함한다. 이대로 나란히 두면 "프루닝 방법"과 "재학습 유무"가 섞인다.

| 선택지 | 표에 들어가는 행 |
|---|---|
| (a) MoOP + 동일 증류 arm 추가 | Minitron(zs), Minitron+KD, MoOP(zs, 기존), **MoOP+KD** — 같은 데이터·step·LR·seed·하드웨어 |
| (b) Minitron만 | Minitron(zs), Minitron+KD — 재학습 예산이 다른 비교임을 명시 |

추천 (a). 동일 재학습 예산 비교가 압축 논문의 통상 관례이고, (b)는 리뷰에서 공정성 지적을 받기 쉽다.

| **MT-W + KD** | 동일 | Minitron 증류 (§2-3 + D1–D3) | 학습 + 평가 |
| **MoOP + KD** | `dual_u40_v2` | 위와 **비트 단위로 같은 레시피** | 학습 + 평가 |
| (2차) MT-D zs / + KD | KV-only 연속 14층 | 동일 | D5(b) 채택 시 |

주 판정(사전 등록, test500 minADE@6 평균, 페어드 부트스트랩 95% CI, `d = MoOP+KD − MT-W+KD`):
CI 상한 < 0 → MoOP 우위 / CI 하한 > 0 → Minitron 우위 / 0 포함 → 구분 불가(|평균|과 함께 보고).
OOD-Val262와 val500은 같은 규칙으로 보조 보고한다.

**검증 게이트 G0 (학습 전):**

- G0-T (teacher 진단, D6 결정, Ada 1장 1시간 이내): dense teacher의 GT 이산 궤적 토큰 NLL과
  flow-matching 손실(추론 격자 10점)을 증류용 train 클립과 official val 클립에서 측정.
  (a) 이산 궤적 토큰 헤드가 의미 있는 분포를 내는지 — D2의 궤적 토큰 KL의 전제. 무너져 있으면 그 KL을
  빼는 것을 다시 논의한다. (b) 두 세트 차이가 작으면 teacher correction 생략의 근거로 기록.

- G0a: hidden 전 채널 유지로 수술 → dense와 출력 동일(CoC 토큰·궤적, 5클립).
- G0b: 일부 채널 수술본 = 같은 채널을 0으로 마스킹하고 RMSNorm 분모를 보정한 참조 경로와
  수치 일치(상대오차 < 1e-3).
- G0c: 제거 파라미터 수가 목표의 ±0.15% 안 (assert).
- G0d: 증류 smoke — 50 step에서 KL·velocity 손실 하강, NaN 없음, 피크 메모리 기록.

teacher 22 GB가 온라인으로 붙는다. 4×A100-80GB(NEURON)에서 FSDP 전체 샤딩이 기본안,

## 8. 위험

- **토큰 예산 3,000배 차이.** Minitron의 회복력은 대규모 증류에서 나온다. 결과가 나쁘면
  "방법이 약하다"와 "예산이 작다"가 구분되지 않는다 → 같은 예산의 MoOP+KD(D11)가 이걸 막는
  유일한 장치이고, 여유가 되면 증류 step에 대한 학습 곡선을 두 arm 모두 기록한다.
- **hidden 축소의 zero-shot 붕괴.** 모든 층의 입력이 바뀌고 RMSNorm 분모도 변하므로 MT-W zs는
  크게 무너질 가능성이 높다. Minitron도 증류 전 모델은 쓰지 않는다 — zs 행은 참고용으로만 보고.
- **fast path 호환.** 지연시간 경로가 hidden 4096을 가정하면 수정이 필요하다.
- **메모리.** 온라인 teacher + 전체 학습이 4×A100에서도 활성 메모리로 빠듯할 수 있음 →
  gradient checkpointing, 필요 시 teacher도 FSDP 샤딩.
